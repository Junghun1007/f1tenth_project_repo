Jetson ROS2 수동 주행 실행 정리
=============================

작성일: 2026-07-09
대상 실행일: 2026-07-10


1. 기본 전제
-----------

Jetson으로 옮길 때는 build/, install/, log/ 산출물을 그대로 믿지 말고,
소스 워크스페이스를 Jetson에서 다시 빌드하는 것을 기준으로 한다.

현재 수동 주행 흐름:

  8BitDo
    -> joy_node
    -> /joy
    -> manual_control_node
    -> /manual/throttle, /manual/steering
    -> manual_to_vesc_node
    -> /vesc/erpm, /vesc/servo_position
    -> vesc_interface_node
    -> VESC serial


2. Jetson에서 필요한 패키지
--------------------------

Ubuntu/ROS2 Humble 기준:

  sudo apt update
  sudo apt install ros-humble-joy python3-serial python3-yaml

사용자 권한:

  sudo usermod -aG dialout,input $USER

권한 적용을 위해 로그아웃/로그인 또는 재부팅이 필요하다.


3. Jetson에서 빌드
-----------------

  cd ~/ROS_Test/autodrive_ws
  source /opt/ros/humble/setup.bash
  colcon build --packages-select manual_control vesc_interface vehicle_bringup
  source install/setup.bash

실행 파일 확인:

  ros2 pkg executables manual_control
  ros2 pkg executables vesc_interface

정상 예:

  manual_control manual_control_node
  manual_control manual_to_vesc_node
  vesc_interface vesc_interface_node


4. 장치 번호 확인
----------------

8BitDo 컨트롤러:

  python3 ~/ROS_Test/controller_input_test.py --list

예:

  /dev/input/js0: 8BitDo ...
  /dev/input/js1: 8BitDo ...

manual_drive.launch.py의 joy_node device_id와 맞아야 한다.

  /dev/input/js0 -> device_id: 0
  /dev/input/js1 -> device_id: 1

VESC 포트:

  ls -l /dev/ttyACM* /dev/ttyUSB*

vesc.yaml의 port와 맞아야 한다.
현재 기본값:

  /dev/ttyACM0


5. ERPM/Servo 변환만 먼저 확인
------------------------------

처음에는 VESC serial 전송까지 바로 확인하지 말고,
컨트롤러 입력이 /vesc/erpm, /vesc/servo_position으로 나오는지 먼저 본다.

터미널 1:

  cd ~/ROS_Test/autodrive_ws
  source /opt/ros/humble/setup.bash
  source install/setup.bash

  ros2 run joy joy_node --ros-args -p device_id:=1 &
  ros2 run manual_control manual_control_node &
  ros2 run manual_control manual_to_vesc_node --ros-args \
    --params-file install/vehicle_bringup/share/vehicle_bringup/config/manual_to_vesc.yaml

device_id는 실제 /dev/input/jsN에 맞게 바꾼다.

터미널 2:

  cd ~/ROS_Test/autodrive_ws
  source install/setup.bash
  ros2 topic echo /vesc/erpm

터미널 3:

  cd ~/ROS_Test/autodrive_ws
  source install/setup.bash
  ros2 topic echo /vesc/servo_position

기대 동작:

  RT 입력 -> 양수 ERPM
  LT 입력 -> 음수 ERPM
  왼쪽 스틱 좌우 -> servo_position 변화

현재 manual_to_vesc.yaml 기준:

  steering -1.0 -> servo 0.25
  steering  0.0 -> servo 0.50
  steering +1.0 -> servo 0.75


6. 전체 수동 주행 launch
-----------------------

장치 번호와 VESC 포트를 맞춘 뒤 실행:

  cd ~/ROS_Test/autodrive_ws
  source /opt/ros/humble/setup.bash
  source install/setup.bash
  ros2 launch vehicle_bringup manual_drive.launch.py

주의:

  manual_drive.launch.py는 현재 vesc_interface_node까지 실행한다.
  VESC가 연결되어 있지 않거나 포트가 다르면 VESC serial open 오류가 날 수 있다.


7. ROS2 daemon 오류 대응
-----------------------

ros2 topic echo에서 다음 오류가 나면:

  RuntimeError: !rclpy.ok()

daemon 재시작:

  ros2 daemon stop
  ros2 daemon start

그래도 안 되면 daemon 없이 실행:

  ROS2CLI_DISABLE_DAEMON=1 ros2 topic echo /vesc/erpm std_msgs/msg/Int32
  ROS2CLI_DISABLE_DAEMON=1 ros2 topic echo /vesc/servo_position std_msgs/msg/Float32


8. 설정 파일 위치
----------------

수동 입력 -> VESC 명령 변환:

  autodrive_ws/src/vehicle_bringup/config/manual_to_vesc.yaml

자율주행 입력 -> VESC 명령 변환 예정:

  autodrive_ws/src/vehicle_bringup/config/auto_to_vesc.yaml

VESC serial 설정:

  autodrive_ws/src/vehicle_bringup/config/vesc.yaml

컨트롤러 키맵:

  autodrive_ws/src/vehicle_bringup/config/manual_keymap.yaml


9. 중요한 개념
-------------

VESC set_rpm expects ERPM, not wheel RPM. ERPM is electrical RPM.

따라서 토픽 이름은 /vesc/erpm을 사용하고,
코드 내부 변수도 target_erpm 또는 erpm 기준으로 해석한다.
