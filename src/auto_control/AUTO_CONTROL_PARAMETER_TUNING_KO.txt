AUTO CONTROL 파라미터 조정 가이드
=================================

현재 기준 설정 (2026-08-16)
----------------------------
아래 값은 auto_drive.launch.py와 auto_control.yaml의 기본값이므로 평소에는
추가 인자 없이 다음 명령만 실행하면 된다.

  ros2 launch vehicle_bringup auto_drive.launch.py

현재 기본값을 명시한 전체 명령은 다음과 같다.

  ros2 launch vehicle_bringup auto_drive.launch.py \
    steering_servo_inverted:=true \
    path_minimum_x_m:=0.05 \
    path_minimum_points:=8 \
    path_minimum_span_m:=0.12 \
    path_local_smoothing_window_m:=0.08 \
    path_outlier_threshold_m:=0.04 \
    path_geometry_window_m:=0.14 \
    stanley_heading_lookahead_m:=0.22 \
    stanley_gain:=1.5 \
    stanley_softening_speed_mps:=0.35 \
    steering_current_weight:=0.65 \
    minimum_duty:=0.055 \
    maximum_duty:=0.065 \
    minimum_speed_mps:=0.6 \
    maximum_speed_mps:=0.9 \
    maximum_lateral_acceleration_mps2:=0.6


안전한 조정 순서
----------------
1. 한 번에 한 종류만 바꾼다: 경로 유효성, 조향, 속도 중 하나.
2. 값을 10~20%씩만 바꾸고 동일 위치를 여러 번 주행한다.
3. 바퀴를 띄운 상태에서 좌/우 조향 방향을 먼저 확인한다.
4. /auto/steering_angle_rad, /auto/path_curvature, /auto/target_speed,
   /auto/current_speed, /auto/current_duty와 auto_control 상태 로그를 함께 본다.
5. centerline_missing 정지는 조향 한계가 아니라 경로 유효성 조건 문제다.


파라미터별 조정 방법
--------------------

[서보 방향]

steering_servo_inverted (현재 true)
  역할: Stanley가 계산한 물리적 조향 방향을 실제 서보 출력으로 보낼 때만 반전한다.
  변경할 때: 오른쪽 경로인데 바퀴가 왼쪽으로 향하는 등 모든 상황에서 실제 바퀴
             방향이 정확히 반대로 움직일 때만 false로 변경한다.
  주의: 코너를 너무 일찍/늦게 도는 현상을 조정하는 값이 아니다.


[짧은 중앙선 허용 조건]

path_minimum_x_m (현재 0.05m)
  역할: 앞차축으로부터 이 X 이상에 있는 중앙선만 제어에 사용한다.
  낮추기: 코너에서 차량 바로 앞의 짧은 중앙선만 남아 centerline_missing으로
          멈출 때. 예: 0.05 -> 0.03.
  높이기: 차량 바로 앞 BEV 노이즈 때문에 조향이 갑자기 튈 때.
          예: 0.05 -> 0.08~0.12.
  부작용: 너무 낮으면 차량 하단 노이즈를 경로로 사용할 수 있다.

path_minimum_points (현재 8개)
  역할: 필터 이후 경로로 인정할 최소 중앙선 점 개수다.
  낮추기: 실제 중앙선이 보이는데 점 수 부족으로 간헐 정지할 때. 최소 허용은 3.
  높이기: 짧은 노이즈 조각을 중앙선으로 오인할 때. 예: 8 -> 10~15.
  부작용: 너무 낮으면 신뢰할 수 없는 몇 개 점만으로 조향한다.

path_minimum_span_m (현재 0.12m)
  역할: 경로로 인정할 중앙선의 최소 전후방 X 길이다.
  낮추기: 급코너에서 선이 옆으로 눕고 X 방향 길이가 짧아 정지할 때.
          예: 0.12 -> 0.08~0.10.
  높이기: 짧은 점군을 경로로 잘못 인식할 때. 예: 0.12 -> 0.16~0.25.
  부작용: 너무 낮으면 선수각과 곡률 계산이 불안정해진다.

세 값 중 하나라도 조건을 만족하지 못하면 경로가 무효가 되어 duty가 즉시 0이 된다.
간헐 정지 시 로그가 centerline_missing이면 이 세 값을 먼저 확인한다.


[중앙선 모양과 요철 억제]

path_local_smoothing_window_m (현재 0.08m)
  역할: 이 폭의 주변 점으로 국소 직선을 계산하여 중앙선의 작은 요철을 평활화한다.
  높이기: 중앙선과 조향이 지렁이처럼 잘게 흔들릴 때. 예: 0.08 -> 0.10~0.14.
  낮추기: 타이트한 코너 모양이 둥글게 깎이거나 코너 반응이 늦을 때.
          예: 0.08 -> 0.06.
  부작용: 너무 높이면 실제 급코너가 완만하게 바뀌고 조향이 늦어진다.

path_outlier_threshold_m (현재 0.04m)
  역할: 주변 중앙값에서 이 거리보다 멀리 튄 독립 점을 주변 값으로 교체한다.
  낮추기: 3~4cm 크기의 고립된 돌출점까지 제거하고 싶을 때.
          예: 0.04 -> 0.025~0.035.
  높이기: 실제 코너 점이 이상점으로 지워지는 것 같을 때. 예: 0.04 -> 0.05~0.07.
  부작용: 너무 낮으면 실제 급격한 곡선 일부도 제거될 수 있고, 너무 높으면 노이즈가
          조향으로 전달된다. 연속된 큰 오검출은 이 값만으로 제거하기 어렵다.

path_geometry_window_m (현재 0.14m)
  역할: 경로 선수각과 곡률을 계산하는 국소 기하 구간의 크기다.
  높이기: 선수각/곡률 값이 프레임마다 요동할 때. 예: 0.14 -> 0.18~0.24.
  낮추기: 급코너를 늦게 알아차리거나 곡률을 지나치게 작게 볼 때.
          예: 0.14 -> 0.10~0.12.
  부작용: 너무 작으면 센티미터 단위 중앙선 계단이 큰 조향과 감속을 만든다.


[Stanley 조향]

stanley_heading_lookahead_m (현재 0.22m)
  역할: 현재 경로의 최근접점보다 얼마 앞의 접선 방향을 선수각 오차로 사용할지 정한다.
  높이기: 코너 조향이 늦고 코너 앞까지 직진하다 멈추거나 바깥으로 밀릴 때.
          예: 0.22 -> 0.25~0.32.
  낮추기: 코너가 멀리 있는데 너무 일찍 꺾을 때. 예: 0.22 -> 0.14~0.19.
  부작용: 너무 높으면 먼 경로 오검출에도 미리 반응한다.

stanley_gain (현재 1.5)
  역할: 차량과 중앙선 사이 횡방향 오차를 되돌리는 힘이다.
  높이기: 직선에서 한쪽으로 치우친 뒤 중앙으로 천천히 돌아올 때.
          예: 1.5 -> 1.7~2.0.
  낮추기: 중앙선을 중심으로 좌우 왕복하거나 코너에서 횡오차 보정이 너무 강할 때.
          예: 1.5 -> 1.1~1.3.
  주의: 코너 진행 방향 자체는 heading 항이 담당한다. gain만 크게 하면 코너 안쪽에서
        heading과 횡오차 보정이 서로 싸울 수 있다.

stanley_softening_speed_mps (현재 0.35m/s)
  역할: 횡오차 보정의 분모에 더해 저속에서 보정이 과도해지는 것을 막는다.
  낮추기: 저속에서 중앙 복귀가 약할 때. 예: 0.35 -> 0.25~0.30.
  높이기: 출발 직후 또는 저속 코너에서 조향이 과격할 때. 예: 0.35 -> 0.45~0.60.
  관계: 작을수록 Stanley 횡오차 보정이 강해지고, 클수록 약해진다.

steering_current_weight (현재 0.65)
  역할: 새 조향값 65%와 직전 조향값 35%를 섞는다.
  높이기: 조향 반응이 늦을 때. 예: 0.65 -> 0.72~0.85.
  낮추기: 서보가 잘게 떨거나 좌우 조향이 꿈틀거릴 때. 예: 0.65 -> 0.45~0.60.
  부작용: 너무 낮으면 급코너 진입이 늦고, 너무 높으면 인식 노이즈가 바로 전달된다.


[속도와 감속]

minimum_duty (현재 0.055)
  역할: 유효 경로가 있을 때 VESC에 보내는 최소 구동 duty다.
  높이기: 모터가 소리만 나거나 출발하지 못할 때. 예: 0.055 -> 0.058~0.062.
  낮추기: 출발이 튀거나 코너 최저 속도가 너무 빠를 때. 단, 정지 마찰보다 낮으면
          차량이 멈춘 뒤 다시 출발하지 못한다.

maximum_duty (현재 0.065)
  역할: PID를 포함한 최종 duty의 상한이다.
  높이기: 직선 최고 속도가 부족할 때. 예: 0.065 -> 0.070부터 소폭 조정.
  낮추기: 전체 주행이 빠르거나 제동 여유가 부족할 때.
  주의: minimum_duty 이하로 설정할 수 없다.

minimum_speed_mps (현재 0.6m/s)
  역할: 곡률 기반 목표 속도의 하한이며 minimum_duty에 대응한다.
  낮추기: 급코너 목표 속도를 더 낮추고 싶을 때.
  높이기: 코너에서 지나치게 느려 모터가 불안정하거나 멈출 때.
  주의: 실제 속도의 직접 하한은 아니다. duty/마찰/ERPM 보정이 맞아야 한다.

maximum_speed_mps (현재 0.9m/s)
  역할: 직선 목표 속도의 상한이며 maximum_duty에 대응한다.
  낮추기: 직선 주행이 너무 빠를 때. 높이기: 직선에서 더 빠르게 달릴 때.
  주의: maximum_duty가 낮으면 이 값을 높여도 실제 속도가 오르지 않는다.

maximum_lateral_acceleration_mps2 (현재 0.6m/s^2)
  역할: 곡률 k에서 sqrt(값/k)로 코너 목표 속도를 계산한다.
  낮추기: 코너 진입 속도를 더 일찍/많이 낮추고 싶을 때. 예: 0.6 -> 0.4~0.5.
  높이기: 완만한 곡선에서도 과하게 감속할 때. 예: 0.6 -> 0.7~0.9.
  주의: 조향 시점이나 조향각은 바꾸지 않고 목표 속도만 바꾼다.


증상별 빠른 선택
------------------
코너에서 centerline_missing으로 멈춤:
  path_minimum_points, path_minimum_span_m, path_minimum_x_m을 순서대로 소폭 낮춘다.

코너를 늦게 꺾음:
  stanley_heading_lookahead_m을 높인다. 그래도 늦으면 path_geometry_window_m을
  조금 낮추고 steering_current_weight를 조금 높인다.

코너를 너무 일찍 꺾음:
  stanley_heading_lookahead_m을 낮춘다. 먼 경로 오검출 여부도 확인한다.

직선에서 중앙 복귀 방향은 맞지만 약함:
  stanley_gain을 높이거나 stanley_softening_speed_mps를 낮춘다.

직선에서 좌우로 왕복함:
  stanley_gain 또는 steering_current_weight를 낮춘다. 중앙선 자체가 흔들리면
  path_local_smoothing_window_m과 path_geometry_window_m을 먼저 높인다.

중앙선/조향이 지렁이처럼 흔들림:
  path_local_smoothing_window_m을 0.10부터 올리고 steering_current_weight를
  0.55~0.60으로 낮춘다. 코너 반응이 늦어지면 일부 되돌린다.

코너 속도가 너무 빠름:
  maximum_lateral_acceleration_mps2를 낮춘다. 최저 속도도 빠르면
  minimum_speed_mps와 minimum_duty를 함께 소폭 낮춘다.

경로는 있는데 차량이 정지함:
  /auto/target_speed와 /auto/current_duty를 확인한다. minimum_duty가 실제 출발
  duty보다 낮거나 VESC/ERPM timeout이 발생하는지 확인한다.


권장 원칙
---------
- 조향 방향이 맞으면 steering_servo_inverted는 더 이상 바꾸지 않는다.
- centerline_missing은 속도나 최대 조향각을 올려 해결하지 않는다.
- 중앙선이 흔들리는 상태에서 Stanley gain부터 높이면 차량 진동이 더 커진다.
- 짧은 코너 경로 허용값을 더 낮출 때는 반드시 BEV 하단 노이즈를 확인한다.
- 한 번의 장면보다 같은 코너를 3회 이상 반복한 결과로 값을 결정한다.
