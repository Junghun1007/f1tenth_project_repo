# VFH 차선 신뢰도·회피 시뮬레이터

저장소 루트에서 다음 명령으로 실행한다. Python 3와 C++17 컴파일러가 필요하다.

```sh
cd src/auto_control/tools/vfh_sim
python3 serve.py --port 8772
```

브라우저에서 http://127.0.0.1:8772/ 를 연다. 소스 변경 후 서버를 재시작한다.
서버는 policy_include의 실험용 계획기, 기존 ROS HazardFilter와
auto_control의 Stanley 제어 코어를 빌드한다. 실차 ROS 패키지의 정책과 별도다.

## 주행 정책

- 신뢰할 수 있는 현재 차선의 추종 궤적이 비어 있으면 차선 추종을 사용한다.
- 장애물이 추종 궤적을 막거나 현재 차선이 신뢰도 검사에 통과하지 않으면 VFH 후보를 검사한다.
- 차선 이탈 거리 상한을 두지 않는다. 차체·패딩과 빨간 위험 셀의 충돌 검사를 적용한다.
- 후보 진행 길이를 우선하고 길이 비교 여유 안에서 장애물 여유, 조향 연속성, 차선 복귀 선호를 비교한다.
- 차선은 일정 시간 연속 검출되고 길이·위치·방향 일관성 조건을 통과해야 기억을 갱신한다.
- 신뢰한 차선 경로를 월드 좌표로 기억하고 차량 이동에 맞춰 현재 좌표로 변환한다.
- 차선을 놓치면 기억 가중치를 exp(-관측 경과시간/감쇠시간 - 마지막 갱신 위치로부터 거리/감쇠거리)로 줄인다.
- 기억 경로 끝을 지나면 마지막 접선 방향으로 연장해 복귀 선호를 계산한다. 관측되지 않은 연장 구간은 가정이다.
- 새 차선도 신뢰도 검사를 통과하고 차체 궤적이 충돌 없이 연결돼야 직접 추종으로 복귀한다.
- 통과 가능한 전진 후보가 없으면 정지한다. 미관측 셀과 격자 밖은 통과 가능으로 가정한다.

## 기본값

| 설정 | 기본값 |
| --- | ---: |
| lengthSlack / 길이 비교 여유 | 0.25m |
| curveSamples / 곡선 샘플 | 13 |
| steeringWeight / 조향 연속성 | 0.5 |
| laneWeight / 복귀 가중치 | 0.5 |
| laneTrustSeconds / 연속 관측 | 0.4초 |
| laneTrustLength / 최소 경로 길이 | 0.5m |
| laneTrustOffset / 관측 위치 일관성 | 0.15m |
| laneTrustAngle / 관측 방향 일관성 | 12도 |
| laneFadeSeconds / 기억 감쇠 시간 | 3초 |
| laneFadeDistance / 기억 감쇠 거리 | 3m |

연속 관측 간격이 0.15초를 넘으면 신뢰도 확인을 다시 시작한다.
차선 복귀 선호는 통로 중심을 명시적으로 찾는 기능이 아니므로 통로 밖 우회를 선택할 수도 있다.
장애물 여유 점수와 후보 곡선 형상에도 선택이 영향을 받는다.

## 로컬 확인

서버 실행 중 이 폴더에서 다음 명령으로 신뢰도·기억 보정·기본값·차선 재관측·
막힌 경로 정지와 세 장면의 충돌 여부를 확인한다.

```sh
node policy-smoke.cjs http://127.0.0.1:8772
```

## 조작과 확인

- 주행 시작·일시정지, 0.1초 진행, 차량 초기화 버튼을 사용한다.
- 차선 관측 체크박스는 주행 상태를 유지하며 유실·재관측을 시험한다.
- 보이는 차선 길이 입력도 즉시 적용된다. 0.2m로 줄여 짧은 조각의 기억 갱신 거부를 확인할 수 있다.
- 나머지 설정은 적용 버튼으로 반영하며 차량을 초기화한다.
- 원·사각형을 추가하거나 이동하고 촘촘한 콘 배열을 드래그로 그릴 수 있다.
- 장면·설정 JSON으로 배치와 설정을 저장·복원한다. 불러온 명시 설정은 기본값보다 우선한다.
- 상태에는 missing / too short / confirming / trusted를 표시한다.
- Mac 처리 시간에는 C++ 계획·hazard 확인·센서 모사·통신 포함 처리 시간을 표시한다.

장애물은 가장 가까운 광선 관측만 terrain으로 변환한다. C++ 계획기는 원본 객체 목록을 받지 않는다.
차선은 이상적인 직선에서 합성하고 차량 위치·속도·yaw·조향이 제공된다고 가정한다.
실제 depth 처리·차선 신경망·센서 동기화·VESC 구동은 모사하지 않는다.
전체 유도 통로 완주와 실제 차량의 통과 가능성을 보장하는 실험은 아니다.
