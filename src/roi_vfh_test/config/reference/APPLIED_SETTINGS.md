# VFH 공유 정책 이식 설정 (2026-11-09)

사용자 결정:
- 차체: 앞차축 기준 앞 0.05m / 뒤 0.45m, 전장 0.50m, 폭 0.30m, 축간거리 0.33m.
- VFH 전용 terrain 셀 0.025m. 나머지 ROI 깊이·지면·표본·고립점 제거 값 유지.
- 장애물 위치 기억은 2026-11-10 제거. 차선 방향각 하나의 기억은 lane_memory_enabled로 선택(기본 ON).

기본 계획값은 config/preview.yaml이 기준이다: 속도 1.0, 계획 1.2, 목표 거리 1.0,
패딩 0.02, 샘플 간격 0.03, 곡선 17, 길이 여유 0.40,
복귀/조향 연속성/장애물 여유 가중치 1.5/0.1/1.0.
차선 밖 한도·통로 상태기는 없으며 마킹도 계획 입력으로 받지 않는다.

참고 auto_control 파일은 하드웨어 제어·속도 환산·서보·입력 만료 기준에 사용한다.
그 파일의 maximum_speed_mps는 GUI 허용 상한이며 VFH 목표 속도 1.0을 대체하지 않는다.
vehicle_half_length_m=0.25를 rear_extent_m로 사용하던 변환은 제거했다.
이전 auto_control/obstacles 프로필의 우회 상태기나 차선 이탈 한도는 실행하지 않는다.

일반 roi_lidar 기본 YAML은 수정하지 않았다. VFH 프로필만 해상도를 통일했다.
기존 Start/Stop, 출발 후 편집 잠금, VESC/PID/브레이크, 입력 유효성 검사를 유지한다.
빌드·테스트·주행은 사용자 요청대로 실행하지 않았다.
