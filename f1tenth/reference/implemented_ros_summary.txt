- vehicle_interfaces/msg 파일들이 비어 있다.
- DriveCommand, ManualDriveCommand, VescState 메시지는 아직 실제 타입으로 사용할 수 없다.

4) vesc_interface 패키지 기반 VESC 통신
- vesc_interface_node.py, vesc_driver.py, vesc_packet.py가 비어 있다.
- 현재 VESC 통신은 루트의 drive_node.py에만 직접 구현되어 있다.

5) launch로 camera_node.py와 drive_node.py 함께 실행
- camera_node.py와 drive_node.py는 패키지에 등록되어 있지 않다.
- vehicle_bringup 런치 파일에도 포함되어 있지 않다.


10. 현재 동작 흐름 요약
----------------------

패키지화된 수동 입력 흐름:

  8BitDo Controller
    -> joy_node
    -> /joy (sensor_msgs/msg/Joy)
    -> manual_control_node
    -> /manual/throttle (std_msgs/msg/Float32)
    -> /manual/steering (std_msgs/msg/Float32)
    -> /manual/controller_debug (std_msgs/msg/String)

루트 단독 자동 주행 흐름:

  OAK Camera
    -> camera_node.py
    -> /lane_error (std_msgs/msg/Int32)
    -> drive_node.py
    -> VESC serial packets

아직 연결되지 않은 부분:

  /manual/throttle + /manual/steering
    -> safety/limit 변환
    -> VESC duty/servo command
    -> vesc_interface_node
    -> VESC
