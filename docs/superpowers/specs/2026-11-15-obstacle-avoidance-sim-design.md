# 라바콘 회피 2D 시뮬레이터 설계

작성일: 2026-11-15 · 상태: 검토 대기

## 1. 목적

실차가 없는 동안 라바콘 회피 알고리즘을 개발·검증한다.
현재 실차(1113ML)는 장애물을 기억하지 않아, 콘이 시야(앞차축 앞)에서 사라지면 바로 중앙선으로
복귀하고 뒷바퀴가 콘에 걸린다. 시뮬레이터는

1. 이 현상을 **재현**하고 (기준 알고리즘),
2. 콘 메모리 + 경로 계획(제안 알고리즘)이 이를 **해결하는지 수치로** 보여준다.

## 2. 목표 / 비목표 / 실패 조건

**목표**
- 대회 트랙(13×4 m) 0~2단계 중 차선 주행, 1단계 라바콘 회피(7·8번), 2단계 유도선(11~13번 + 보조 A~C) 재현
- 카메라 한계(BEV 시야, 앞 콘에 가린 뒤 콘 미관측) 반영
- 기존 Stanley·가감속 파라미터 그대로 사용
- 회피 알고리즘을 교체 가능한 구조로 두고 기준안/제안안 비교
- 화면 모드(애니메이션)와 배치 모드(반복 실행 + 지표 표) 제공

**비목표**: 터널, 신호등, 동적 장애물(RC카), ROS 연동, VESC duty/전류 수준 모델, 카메라 영상 렌더링·YOLO 실행, C++ 이식

**실패 조건 (동작해도 실패로 본다)**
- 기본 설정에서 인지가 완벽해서(노이즈·가림 없음) 통과하는 시뮬 → 기본값은 노이즈·가림·지연 ON
- 기준 알고리즘으로 1단계 뒷바퀴 접촉이 재현되지 않음 → 차량/인지 모델이 너무 낙관적이라는 신호이므로 원인 확인 후 보고

## 3. 사용자가 정한 것

- 차선: BEV + 추론 모델로 이미 알고 있다고 가정
- 객체: `multiclass_yolo`처럼 위치와 크기를 추정한다고 가정
- 조향: Stanley, 가감속은 `auto_control` 방식을 참고
- 카메라: 장애물 뒤의 장애물은 볼 수 없음
- BEV 시야: 가로 1.2 m × 세로 3 m
- 구현: 전부 Python (빠른 실험 우선, 실차 이식은 나중에 재작성)
- 구성: numpy + matplotlib, 화면 모드 + 배치 모드

## 5. 좌표계와 트랙

### 5.1 월드 좌표
- 원점은 트랙 왼쪽 아래(20번 매트 바깥 꼭짓점), x 오른쪽 0~13 m, y 위쪽 0~4 m. 매트는 1 m 격자
- 매트 배치: 아래줄 y∈[0,1]: 20(코너) 21 … 30 1 2(코너)가 x=0→13. 오른쪽 열 x∈[12,13]: 3(y 1~2), 4(y 2~3), 5(코너).
  윗줄 y∈[3,4]: 5(코너) 6 7 … 16 17(코너)이 x=13→0 (6번 x 11~12, 7번 x 10~11, 11번 x 6~7, 13번 x 4~5).
  왼쪽 열 x∈[0,1]: 18(y 2~3), 19(y 1~2)
- 반시계 주행: 아래줄 +x, 오른쪽 +y, 윗줄 −x, 왼쪽 −y

### 5.2 차선
- 차선 중심선: 모서리가 둥근 직사각형. 직선 y=0.5(x 1~12), x=12.5(y 1~3), y=3.5(x 12~1), x=0.5(y 3~1).
  코너는 코너 매트 안쪽 꼭짓점 (12,1), (12,3), (1,3), (1,1)을 중심으로 반지름 0.5 m 사분원. 한 바퀴 ≈ 29.14 m
- 테이프 중심은 중심선에서 좌우 ±0.34 m (코너 반지름 0.16 / 0.84 m), 테이프 폭 0.03 m
- 주행 가능 차선(테이프 안쪽 끝 사이) 폭 0.65 m
- 출발: 30번 중앙 (10.5, 0.5), 진행 방향 +x

### 5.3 1단계 라바콘 (7·8번, 8개)
- 윗줄을 −x 방향으로 달리므로 진행 기준 왼쪽 = 루프 안쪽(−y), 안쪽 테이프 중심 y=3.16, 바깥 테이프 중심 y=3.84
- 지점 x = 10.75, 10.25, 9.75, 9.25 (각 매트 진입 가장자리 기준 25 cm, 75 cm), 순서 왼·오·왼·오
- 한 지점에 13×13 cm 콘 2개를 가로로 붙임. 바깥 콘 중심은 테이프 중심, 안쪽 콘은 차선 안쪽으로 붙임
  - 왼쪽 지점: 콘 중심 y = 3.16, 3.29
  - 오른쪽 지점: 콘 중심 y = 3.84, 3.71
- 결과: 차선 안쪽 끝에서 18 cm 돌출, 남는 폭 47 cm. 차폭 30 cm → 양옆 여유 8.5 cm
- 요구: **차선을 벗어나지 않고** 회피

### 5.4 2단계 유도선 (11~13번 + 보조 A~C, 38개)
- 진행 거리 s ∈ [0, 3.0] m, 11번 시작 x=7에서 출발, 13번 끝 x=4에서 복귀 (월드 x = 7 − s)
- 유도선 중심: 진행 왼쪽(−y)으로 l(s) = 0.34 (1 − cos(2π s / 3.0)) → 월드 y = 3.5 − l(s). 최대 0.68 m (12번 중앙 x=5.5)
- 콘: 중심선에서 법선 방향 ±0.34 m, 양쪽 19개씩. **중심선 호 길이 기준 등간격**(≈18.6 cm, 양 끝 포함)
  - 검증: s=0, 3.0에서 콘은 y=3.16, 3.84(기존 테이프)에 놓이고, s=1.5에서 오른쪽 줄은 y=3.16
- 보조 매트 A~C(y 2~3, x 4~7)는 테이프 없는 검은 매트. 기존 차선 테이프는 11~13번 위에 그대로 있음
- 요구: 차선을 막고 있으므로 **차선을 벗어나 콘 통로로** 주행

## 6. 차량 모델

- 기구학 자전거 모델, 상태 = 뒷차축 중심 (x, y, ψ), 속도 v, 조향각 δ
- 치수: 휠베이스 0.33 m, 전장 0.50 m, 전폭 0.30 m, 앞차축→앞범퍼 0.05 m, 뒷차축→뒷범퍼 0.12 m
- 조향: 최대 30°, 변화율 240°/s, 명령 필터 `δ ← 0.4·δ_cmd + 0.6·δ_prev` (auto_control `steering_current_weight`)
- 속도: 목표 속도를 1차 지연(τ 0.2 s)으로 추종, 가속 한계 1.0 m/s², 감속 한계 2.0 m/s² *(구현자 결정: duty/전류 모델 대신 단순화)*
- 시뮬 적분 1 ms, 제어 100 Hz, 인지 30 Hz

## 7. 인지 모델

모든 인지 결과는 auto_control과 같은 **앞차축 기준 차량 좌표**(x 앞, y 왼쪽)로 나온다.

### 7.1 BEV 시야
앞차축 기준 x ∈ [0, 3.0], y ∈ [−0.6, 0.6] 직사각형 (`bev_x_max_m 3.0`, `bev_y_max_m 0.60`)

### 7.2 차선
- 시야 안의 차선 중심선과 좌우 테이프를 실제값에 노이즈(횡 σ 1 cm, 기본값)를 더해 0.05 m 간격 점열로 제공
- 콘에 의한 차선 가림은 모델링하지 않음

### 7.3 콘 (multiclass_yolo 방식 흉내)
1. 카메라 위치: 앞차축 중심(파라미터, 기본 x=0)
2. **가림**: 카메라에서 본 각 콘의 각도 구간을 구하고, 더 가까운 콘들이 덮는 부분을 뺀다.
   보이는 비율 ≥ 0.5(파라미터)이고 보이는 앞면 중심이 BEV 시야 안이면 관측 후보
3. 검출 확률 0.95 (오검출 기본 OFF)
4. 측정: 앞면 거리 = 실제 앞면 거리 + N(0, (0.01 + 0.02·r)²), 방향 = **보이는 각도 구간의 가운데** + N(0, 0.5°)
   (부분 가림이면 방향이 실제 중심에서 치우침 → 실차와 같은 오차)
5. 앞면에서 시선 방향 뒤로 13×13 cm 사각형을 놓아 중심과 네 꼭짓점 출력
6. 지연: 촬영 시각 기준 50 ms 후 사용 가능 (파라미터)

### 7.4 오도메트리
- 속도: 실제 v × (1 + N(0, 0.02))
- 요레이트: 실제 ψ̇ + 바이어스 0.5°/s + N(0, 0.3°/s)
- 제안 알고리즘만 사용 (기준 알고리즘은 실차처럼 사용하지 않음)

## 8. 제어 (두 알고리즘 공통)

### 8.1 Stanley (auto_control `stanley_control` 이식)
- 입력 경로는 앞차축 기준 점열. 가장 가까운 선분으로 횡오차, 그 지점 + 0.05 m에서 경로 방향 오차
- `δ = 방향오차 + atan2(1.3·횡오차, |v| + 0.3)`, 코너 가드(60°, 0.8), ±30° 제한

### 8.2 속도 계획 (auto_control `plan_path_speeds` 단순화)
- 경로 0.05 m 간격 곡률 한계 `v = clamp(sqrt(1.6/|κ|), 1.0, 1.8)`, 앞뒤 한 칸 팽창
- 뒤로 전파(감속 0.5 m/s²) / 앞으로 전파(가속 0.35 m/s²)
- 차선 안 장애물이 보이거나(기준) 기억 중이면(제안) 상한 1.0 m/s, 감소율 0.35 m/s², 해제 후 1.0 s 유지
- 경로 시작점 계획 속도를 목표 속도로 사용

## 9. 회피 알고리즘

공통 인터페이스: `plan(lane, detections, odom, t) -> path(앞차축 좌표 점열), debug`

### 9.1 기준안 `baseline` (현재 실차 재현)
- 메모리 없음. 현재 프레임 콘만 사용 (오래된 결과는 0.25 s 후 폐기)
- 콘을 중앙선에 투영하고, 좌우 차선 사이에 있는 콘만 사용
- 왼쪽 콘이면 오른쪽, 오른쪽이면 왼쪽으로 중앙선 이동. 이동량 = 차량 반폭 + 콘 반폭 + 여유 − 횡거리 (음수면 0), `max_offset` 제한
- 이동 구간 앞뒤는 부드럽게 연결(전이 길이 파라미터)
- 1113ML `avoidance_planner.hpp`의 변형 모드를 참고하되 완전한 이식은 아님

### 9.2 제안안 `proposed`
1. **오도메트리 적분**: 속도·요레이트로 자차 자세 추정 (odom 좌표)
2. **콘 메모리 (최근접 이웃 추적)**
   - 관측을 odom 좌표로 바꿔, 게이트 0.12 m 안 가장 가까운 기존 콘과 연결, 위치는 관측 횟수 가중평균
   - 2회 관측되면 확정
   - 자체 가림 모델로 "보여야 하는데 안 보인" 콘만 신뢰도 감소, 시야 밖·가려진 콘은 유지
   - 앞차축 기준 x < −(0.45 + 0.10) m가 되면 삭제
3. **기준선 메모리**: 관측한 차선 중심선을 odom 좌표로 저장해 앞차축 뒤 0.6 m까지 기준선을 이어 붙임
4. **Frenet 격자 DP**
   - 기준선 s ∈ [−0.5, 3.0] m, 간격 0.1 m / l ∈ [−1.0, 1.0] m, 간격 0.05 m
   - 시작 제약: s=0에서 현재 횡오프셋 근처
   - 비용: 콘과의 차체 여유(0 미만이면 금지, 여유 부족은 큰 비용), 차선 이탈(차체가 차선 밖으로 나간 양의 제곱, **soft**),
     중심선 오프셋, 1·2차 변화(부드러움)
   - 차체는 경로를 따라 놓인 원 3개(앞범퍼, 중앙, 뒷범퍼 위치)로 근사 → 뒷부분이 콘 옆을 지나는 구간까지 검사
   - 차선이 뚫려 있으면 차선 안(1단계), 막혀 있으면 밖(2단계)이 자동 선택됨
5. **최종 충돌검사**: 선택 경로를 Stanley + 자전거 모델로 1.5 s 미리 굴려, 차체 사각형과 기억 콘을 SAT로 검사.
   충돌이면 여유를 늘려 1회 재계획, 그래도 실패면 속도를 최저로
6. 출력은 s ≥ 0 부분을 앞차축 좌표 점열로 변환

## 10. 시나리오

YAML로 정의: 시작 위치·방향, 종료 조건, 활성 장애물 세트, 노이즈 시드

- `stage0_lap`: 장애물 없이 한 바퀴 (차선 추종·속도 계획 확인)
- `stage1_cones`: 6번 시작 근처에서 출발 → 9번 끝 통과 시 종료
- `stage2_guide`: 10번 시작 근처에서 출발 → 14번 끝 통과 시 종료
- `full_lap`: 30번에서 출발해 1·2단계 포함 한 바퀴

## 11. 지표 (실행마다)

- 콘 접촉 횟수와 접촉한 콘 ID, 접촉 부위(앞/옆/뒤)
- 차체–콘 최소 여유 (m)
- 1단계 차선 이탈: 차체가 차선 안쪽 끝(±0.325 m) 밖으로 나간 최대량

배치 모드: 시나리오 × 알고리즘 × 시드 N개 → CSV + 요약 표 출력

## 12. 화면

- 왼쪽: 트랙 전체 위에서 보기 (매트 격자, 테이프, 콘, 차량 사각형, 지나온 궤적, BEV 시야 사각형)
- 오른쪽: 앞차축 기준 확대 보기 (실제 콘, 관측된 콘, 기억 중인 콘, 기준선, 계획 경로, DP 격자 선택)
- 접촉 시 콘·차량 빨간색 표시, 상단에 시간·속도·조향·지표
- 키: 스페이스 일시정지, ←/→ 재생 속도. `--save out.gif` 저장 지원

## 13. 코드 위치와 실행

- 위치: `tools/avoidance_sim/` (ROS 패키지와 분리된 Python 패키지)

- 실행 예

- 트랙 기하: 한 바퀴 길이, 코너 반지름, 1단계 남는 폭 0.47 m, 2단계 콘 간격과 최대 이탈 지점
- 가림: 일렬로 선 콘에서 뒤 콘 미관측, 부분 가림 시 방향 치우침
- Stanley: auto_control과 같은 입력에 같은 출력 (몇 개 고정 사례)
- 메모리: 시야를 벗어난 콘이 차량 이동 후에도 올바른 위치에 남는지, 차량 뒤로 지나가면 삭제되는지
- 통합: `stage0_lap`에서 접촉 0, `stage1_cones`에서 기준안 접촉 재현 여부 기록

## 15. 구현자에게 맡긴 것 (설계 시 내린 결정)

- 속도 1차 지연과 가감속 한계 수치 (duty/전류 모델 대체)
- 노이즈 수치, 검출 확률, 지연 50 ms
- 카메라 위치 = 앞차축 중심
- 2단계 콘 간격 규칙 (중심선 호 길이 등간격)
- DP 격자 간격·비용 가중치 초기값 (튜닝 대상)
- 콘 메모리 게이트·확정 횟수·삭제 거리
